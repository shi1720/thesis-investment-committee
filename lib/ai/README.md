# Account AI and research runtime

NVIDIA is the initial provider. No model is selected and no connection is claimed until the account saves a key, discovers its live catalog, selects a role model and tests an actual inference request. OpenAI, Anthropic and Gemini use their own native APIs. Nightshift is an optional operator-managed route. Account keys never become browser configuration; the host encrypts each key using account and purpose as authenticated associated data. Public settings expose configuration state and the final four account-key characters.

Model choices come from vendor catalog responses. There is no bundled “latest models” list or guessed replacement model. Catalog access is distinct from inference access, and a catalog item may have unverified text capability. Native API generation failures, refusals, truncation and unavailable credentials do not produce fabricated fallback research. POST generation is never automatically retried. A caller may initiate another separately counted request after seeing the error. Catalog GETs have one bounded transient retry.

The server runs planning, fundamental analysis, quantitative interpretation, news analysis, skepticism, revision and evaluation using six independently configurable roles. The planner also performs revision. Each accepted narrative is a model response, with a source registry and usage receipt. The model can request bounded server tools through a validated JSON protocol; native provider function calling is not assumed for unfamiliar models. Only trusted quote, history, fundamentals, news and optional search adapters execute. There is no tool that fetches an arbitrary model-supplied URL.

Numeric market values, historical calculations and allocation weights remain in deterministic data panels. Model prose is qualitative: digits, explicit return guarantees, invented deposit rates and certain forecast patterns are rejected. Citation IDs must exist and cannot cite another security. These checks do not prove semantic entailment. Reports explicitly retain that limitation, missing sources and undated context. A research report without dated company market evidence cannot accept a stock thesis. News-index observations are distinguished from confirmed article publication dates. News article bodies are never fetched by this module.

For plan review, trusted server code may provide up to two dated `mandate` or `policy` artifacts, bounded to 8,000 serialized sanitized characters. These represent the validated user profile, computed allocation and actual rule provenance. A cash-only plan can therefore receive a cited qualitative review without inventing a need for quotes, news or deposit rates. The artifacts remain planning context and cannot qualify a stock research thesis. They are not accepted through the HTTP research body, and structured credential fields are removed before model context is assembled. Model critique never mutates the deterministic allocation.

Call count, tool count, total reported tokens, response bytes and wall time are bounded. Unknown usage stops subsequent generation. Token usage includes reported Gemini thought tokens and Anthropic cache input tokens. Monetary cost remains unknown unless explicitly reported by the provider. The Nightshift operator route has a smaller structured context projection, a maximum output of 1,050 tokens and a preflight estimate against a 4,096-token context. That estimate is not a tokenizer guarantee; provider truncation still fails closed. Large mandates must use a suitable cloud model or a smaller scope. No JSON document is cut at an arbitrary character offset to force it into the operator context.

The tests in `tests/ai-platform.test.ts` use mock transports and fixture sources. They verify integration contracts and failure behavior, not live account access. A separate actual Nightshift connection test passed on 27 October 2026 with its concrete Qwen model. The new direct NVIDIA, OpenAI, Anthropic and Gemini adapters have not been tested with customer keys. NVIDIA remains waiting for the user's key.

Official API references checked on 27 October 2026:

- [NVIDIA hosted model catalog](https://docs.nvidia.com/nim-operator/latest/guardrail.html) and [NIM chat completions](https://docs.api.nvidia.com/nim/reference/llm-apis).
- [OpenAI model catalog](https://developers.openai.com/api/reference/resources/models/methods/list) and [Responses text generation](https://developers.openai.com/api/docs/guides/text). Requests set `store:false` and accept completed output-text messages only.
- [Anthropic model catalog](https://platform.claude.com/docs/en/api/models/list), [Messages](https://platform.claude.com/docs/en/api/messages/create) and [API versions](https://platform.claude.com/docs/en/api/versioning). The adapter pins documented version `2026-10-21` with Bearer API-key authorization.
- [Gemini model catalog](https://ai.google.dev/api/models) and [GenerateContent](https://ai.google.dev/api/generate-content). Only catalog entries supporting `generateContent` are offered.
- [Brave web search](https://api-dashboard.search.brave.com/api-reference/web/search/get) and [Tavily search](https://docs.tavily.com/documentation/api-reference/endpoint/search). These use separate account search keys, fixed endpoints and bounded untrusted snippets. Provider-native web search is not enabled or assumed in this implementation.
