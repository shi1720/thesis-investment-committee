# Launch readiness

Thesis is a tested, publicly deployed hackathon implementation for the
**Reasoning Architecture** track. The public application is
[thesis-investing.web.app](https://thesis-investing.web.app). This document
separates verified behavior from commercial prerequisites.

## Implemented and exercised

- Firebase anonymous authentication and server-verified, account-scoped access.
- Durable named-Firestore history, saved theses, notes, export and reset. The
  alternate Sites deployment retains its platform identity and D1 store.
- Strict preferences, streamed request/provider limits, same-origin mutation
  defenses, idempotency and per-account/shared live-provider budgets.
- Actual typed critique/revision, source-integrity checks, recomputed risk,
  watch-only FX protection and explicit abstention.
- Persistent Cloud Tasks dispatch and polling for connected research, with signed
  internal executor authentication, bounded leases and no blind paid-call replay.
- Official Meterless H-MEM recall, bounded current context and separate audit
  archives, with erasure/deletion race safeguards.
- Comparison, saved invalidation conditions, authenticated reports and account
  exports with bounded reads and response backpressure.
- Twenty-record Zetaris federation from three source feeds, actual Nightshift
  execution, and a completed public connected application run. Public financial
  examples remain synthetic.
- An optional actual private US import with a validated record, SEC fact lineage
  and private Zetaris namespace. Commercial redistribution is not authorized.
- Eighty-four automated tests and nineteen hosted API checks recorded at this
  review snapshot, including real UID isolation and erasure. Fresh reproduction
  evidence is maintained separately.

## Required before selling live access

- Obtain appropriate market-data display and redistribution entitlements for the
  intended exchanges, fields, jurisdictions and users. Personal access and a free
  API key do not establish commercial rights.
- Expand actual provider coverage through reviewed company/security mappings,
  timestamps, corporate-action lineage and complete financial inputs. One
  validated US record does not establish current coverage of four markets.
- Calibrate research heuristics against reviewed cases, including sector-specific
  leverage/accounting differences. Neither fit nor derived quality is a validated
  probability of return.
- Validate source freshness, missing sessions, restatements, delistings, corporate
  actions and currency changes across the supported universe.
- Move the temporary sponsor gateway/tunnel and local inference dependencies to
  stable always-on infrastructure with operational ownership and bounded costs.
- Complete external security review, monitoring/alerting, abuse/load testing,
  backup/restore exercises, spend limits and a documented retention policy.
- Define operator handling for failed queue dispatch, interrupted inference and
  ambiguous provider billing. Current one-attempt execution requires reviewed
  manual retry; it is not resumable inference.
- Review investment-research/advice boundaries and product marketing for the
  intended jurisdictions. No compliance certification is claimed.
- Validate user benefit, repeat use, willingness to pay and total variable cost.
  Proposed pricing is a hypothesis; no customer traction or alpha is established.

## Financial and operational limits

Return targets are aspirations. Historical drawdown is not a future loss cap.
Risk metrics use listing-currency price returns. A different listing currency is
watch-only without aligned FX history; a displayed reporting currency does not
convert the series. Dividends, fees, taxes, liquidity and portfolio correlation
need separate modeling. Stress scenarios use stated assumptions rather than a
calibrated forecast.

The actual personal-use importer preserves dated annual and balance-sheet facts.
Its P/E, yield and market-cap calculations are explicit dated proxies. Missing
required facts cause rejection instead of zero filling. Provider endpoint
availability does not grant commercial reuse rights.

Schema/citation checks reject malformed or unsupported references, but do not
prove every model sentence true. The optional Nemotron feature has separate real
receipts; the recorded public connected run used Qwen only. No automated trades,
portfolio allocation orders, brokerage connection or payment/subscription billing
are implemented.

Public sample mode can run without local sponsor services. Connected work depends
on the authenticated gateway and those services remaining reachable. Recorded
success proves the exercised workflow, not continuous availability or a latency
SLA.
